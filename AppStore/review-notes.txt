Face Hugger is an independent macOS client for Hugging Face uploads. The supplied password is a Hugging Face access token, not an account password.

1. Open Face Hugger Settings. Paste the supplied token into Access token, then click Connect.
2. Choose the dataset repository zakkeown/face-hugger-app-review-89503494.
3. Select a harmless local folder and set the destination to reviewer-test. Start the upload.
4. You may browse the repository and delete individual test files.

This token is restricted to the dedicated private review dataset and cannot create arbitrary repositories. Use only harmless review data in this repository. No account signup or purchase is needed for the supplied review access.

Dataset-card editor:
After selecting the local folder and dataset repository, click Dataset card… beside the repository folder controls. Enter a short purpose, source, license if known, and limitations. Use template works on every supported Mac. Draft on this Mac optionally rewrites the purpose into an overview using Apple's on-device Foundation Models when Apple Intelligence is available; if unavailable, the editor explains why and the template remains usable. File totals and license/provenance are deterministic, not inferred by the model. Dataset contents are not sampled, and no cloud generation is used.

Review/edit the Markdown, or compare it with an existing local README using Changes. Save README as… opens the native save dialog. This only writes a local file and does not publish anything. Unknown fields remain TODOs for the user to complete. Uploading a saved card is a separate explicit upload action; a repository card belongs at repository root.

The app uses only Apple system networking/cryptography. It bundles no Python, OpenSSL, or Xet runtime. Apple Intelligence is optional; it is not needed to test uploads, browsing, or the dataset-card template.
